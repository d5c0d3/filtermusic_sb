Browse FilterMusic.net radio stations from within Lyrion Music Server

Features at a glance

Feature What it gives you
Browse by genre Organized by FilterMusic.net's own categories (House/Dance, Techno/Trance, Jazz, Rock/Metal, etc.)
Direct playback Each station plays straight from the stream URL - no extra page fetch
Station artwork and descriptions For every entry, read directly from FilterMusic.net's feed
Screensaver Image Viewer source FilterMusic.net artwork as a selectable screensaver source on Jivelite-based players (Squeezebox Touch/Radio, SqueezePlay), once enabled in Settings
Resilient to changes Falls back to last successful load if FilterMusic.net is down or the feed format changes
Lightly cached Successful loads cached for 5 minutes to avoid repeated refetches

Quick start

  1. In LMS: Settings → Plugins → Additional Repositories, add: 
    https://d5c0d3.github.io/filtermusic_sb/repo.xml
  2. Install the FilterMusic plugin from the plugin list
  3. Restart LMS
  4. Browse to Radio → FilterMusic to start exploring stations

Manual installation

Manual. Download FilterMusic.zip from the repository, unzip it into your LMS Plugins/ directory so it sits as Plugins/FilterMusic/, and restart: 

sudo rm -rf /var/lib/squeezeboxserver/Plugins/FilterMusic
sudo unzip FilterMusic.zip -d /var/lib/squeezeboxserver/Plugins/
sudo chown -R squeezeboxserver:nogroup /var/lib/squeezeboxserver/Plugins/FilterMusic
sudo systemctl restart lyrionmusicserver

Requirements

  • Lyrion Music Server / Logitech Media Server 8.0 or newer
  • Station logos need LMS 9.1.0+ (WebP support via image proxy)

Using it

Browsing stations

Open Radio → FilterMusic to see the complete genre list. Each genre contains stations curated by FilterMusic.net, with artwork and descriptions. Tap any station to start playing immediately.

Note: On the classic skin, FilterMusic appears under Extras → FilterMusic.

Screensaver Image Viewer

Open Settings → Advanced → FilterMusic and enable Show in Image Viewer (off by default) to add FilterMusic.net's artwork as a selectable source for the screensaver Image Viewer on Jivelite-based players (Squeezebox Touch/Radio, SqueezePlay).

Each wallpaper includes title and artist/photographer credit when available. Images are served through LMS's own image proxy for compatibility.

Notes & limitations

Station logos need LMS 9.1.0 or newer. The feed's logo URLs are WebP. LMS's artwork resizer can't decode WebP on versions older than 9.1.0. Upgrade your LMS/Lyrion server to resolve this.

Classic skin limitation: The literally-named "Classic" skin has no artwork support for audio items, regardless of LMS version or image format.
